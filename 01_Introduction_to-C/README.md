# 🧠 Introduction to C

C is a powerful, general-purpose programming language developed in the 1970s by Dennis Ritchie.  
It is widely used for system programming, embedded systems, and building operating systems.

## ✨ Why Learn C?
- Helps you understand how software interacts with hardware
- Improves your problem-solving and logic building
- Builds strong foundational knowledge for learning other languages like C++, Java, or Python

## 📌 What You'll Learn in This Section
- History and features of the C language
- Structure of a basic C program
- How to write, compile, and run your first C program
