# 🧠 Introduction to C

C is a powerful, general-purpose programming language developed in the 1970s by Dennis Ritchie.  
It is widely used for system programming, embedded systems, and building operating systems.

## ✨ Why Learn C?
- Helps you understand how software interacts with hardware
- Improves your problem-solving and logic building
- Builds strong foundational knowledge for learning other languages like C++, Java, or Python

## 📌 What You'll Learn in This Section
- History and features of the C language
- Structure of a basic C program
- How to write, compile, and run your first C program

C is a structured programming language that allows you to write clean, efficient, and maintainable code. Every C program follows a particular structure or form.

---

## 📐 Structure of a C Program

A basic C program is generally made up of the following parts:

1. *Preprocessor Statements*
   - Begins with #, like #include <stdio.h>
   - Used to include libraries or define constants

2. *Global Variable Declarations*
   - Variables declared outside of all functions
   - Accessible by all functions in the program

3. *main() Function*
   - Every C program starts executing from the main() function
   - This is the entry point of the program

4. *Local Variable Declarations*
   - Variables declared inside a function (like inside main)
   - Only accessible within that function

5. *Set of Statements*
   - The actual instructions your program runs, like printf, scanf, calculations, etc.

6. *User-Defined Functions*
   - Custom functions written by you for organizing logic
   - Called from main() or other functions

7. *Local Variable Declarations (inside sub-functions)*
   - Each function can have its own variables

8. *Set of Statements (inside sub-functions)*
   - The logic or operations handled by that function
