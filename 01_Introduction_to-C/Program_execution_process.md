# ⚙️ Program Execution Process in C

When we write a C program, it does not immediately run. It goes through several steps involving compiling, linking, and loading. Here's a simple explanation of how it works:

---

## 🔄 Step-by-Step Execution Flow

1. *Source Code (.c file`)*  
   You write the code in a file like areaofcircle.c.

2. *Compiler*  
   - Converts the .c file into an *object file* (.obj)
   - Checks for *syntax errors*
   - Example output: areaofcircle.obj

3. *Linker*  
   - Combines the object file with *library files* like stdio.h, math.h
   - Produces an executable file (.exe)

4. *Executable (.exe)*  
   - The final file that runs the program
   - Shows the *output* to the user

5. *Loader*  
   - Loads the .exe file from *hard disk* to *RAM*
   - Program starts executing in memory
